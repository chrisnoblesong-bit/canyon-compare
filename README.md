# 캐년 비교 | LA 출발 그랜드캐니언 투어

한국어 Next.js 웹사이트입니다. 상품 출처, 비교 UI와 날짜/인원 입력, LA 왕복·편도 구분, 가격/후기 정렬, 추가 비용 안내가 포함되어 있습니다.

## 초보자 배포
1. GitHub에서 새 저장소를 만들고 이 폴더의 모든 파일을 업로드합니다.
2. [Vercel](https://vercel.com)에 로그인해 **Add New → Project**에서 해당 GitHub 저장소를 가져옵니다.
3. **Deploy**를 누릅니다. Vercel은 Next.js를 자동 설정하고 이후 GitHub 변경도 자동 배포합니다.

별도 환경변수는 필요하지 않습니다. 앱은 승인된 실시간 가격 API가 연결되지 않은 상태를 분명히 보여주며 예약 사이트를 스크래핑하지 않습니다. 공개 시작가도 날짜별 가용성/결제액을 보장하지 않으므로 원본에서 확인해야 합니다. 조사 내역은 [SOURCES.md](./SOURCES.md)에 있습니다.

## 로컬 미리보기
Node.js 20 이상 설치 후 `npm install` → `npm run dev`, 브라우저에서 `http://localhost:3000`을 여세요.

상품 정보는 `data/tours.ts`에서 수정합니다. 미확인 가격은 숫자 대신 `null`로 둡니다. `/api/prices`는 자동 연동 상태가 아님을 반환합니다.
